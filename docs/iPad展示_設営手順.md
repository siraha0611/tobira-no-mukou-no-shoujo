# 『扉のむこうの少女』iPad展示 設営手順

作成: 2026-07-19 ／ 対象: **iPad 1台だけ**で長時間・無人運転する実物展示

---

## 0. しくみ(30秒でわかる版)

- 展示URLを**一度ネットのある場所で開けば**、アプリの殻がiPadに記憶され(Service Worker)、以後は**会場にネットが無くても起動できる**。
- 会話の脳は2段構え:
  - **ネットあり** → クラウドのClaude(本物の自由会話)
  - **ネットなし/不安定/日次上限** → **内蔵の綾香(台本エンジン)** に自動で切り替わり、展示は止まらない
- 来場者の入力も2段構え:
  - **ネットあり** → 声(iPadの音声認識。Appleのサーバを使うためネット必須)
  - **ネットなし/マイク不調** → 自動で**タッチ運転**(ことばのボタン+文字入力)に切り替え
- 綾香の声は**iPad内蔵の音声合成**(オフラインでも鳴る・¥0)。

## 1. 展示URL（本番用・クラウド音声コハク採用 2026-07-19決定）

```
https://tobira-no-mukou-no-shoujo-web.anb14625siraha.workers.dev/?mode=exhibit&ttsbase=off&tts=cloud
```

- 声はクラウドの**コハク(せつなめ)**。従量 ¥440/万字・上限40,000字/日(最大¥1,760/日)。ネット断・上限到達時は自動でiPad内蔵音声に切り替わり、展示は止まらない。
- **クレジット表記「voice: コハク — AivisSpeech（© Oz Chat ／ CV: ねゆたろ）」は画面右下に自動表示**(ACML 1.0の義務。展示キャプションにも書くとより丁寧)。
- ⚠️会場にネットが無い日は `&tts=cloud` を外す(内蔵音声で運転)。

### URLパラメータ(必要なときだけ)

| パラメータ | 既定 | 意味 |
|---|---|---|
| `mode=exhibit` | — | 展示モード(必須) |
| `ttsbase=off` | 127.0.0.1:10101 | ローカル音声合成エンジンの探索を止める。**iPad単体は必ずoff**(探索の待ちを無くす) |
| `brain=offline` | auto | 脳を内蔵の綾香(台本)に固定。**ネットが無い会場と決まっているならこれを付ける**(接続試行の待ちも消える) |
| `tts=cloud` | free | クラウド音声(コハク・従量¥440/万字)を使いたい時だけ。ネット必須 |
| `idle=110` | 110秒 | 無応答でお別れするまでの秒数 |
| `rest=18` | 18秒 | 結末後、次の来場者を待つまでの秒数 |

## 2. 前日までにやること(ネットのある場所で)

1. iPadの**Safari**で上の展示URLを開く → いちど正常に表示されるのを確認(この時点で殻がiPadに記憶される)。
2. マイク許可を求められたら**「許可」**。
3. 設定アプリで:
   - **画面ロック: なし**(設定 > 画面表示と明るさ > 自動ロック > なし)
   - **音量**: 最大付近にして実際に聴いて調整
   - **おやすみモード/集中モード: オフ**、**通知: 可能なら勝手に出ないように**
   - **アクセスガイドを有効化**(設定 > アクセシビリティ > アクセスガイド > オン、パスコード設定)
   - **綾香の声を良くする(推奨・¥0)**: 設定 > アクセシビリティ > **読み上げコンテンツ > 声 > 日本語** で
     **「O-Ren(オーレン)」**(無ければ「Kyoko(拡張版/プレミアム)」)を**ダウンロード**(数百MB・Wi-Fi推奨)。
     ダウンロード後にSafariを再読み込みすると、アプリが自動で良い声を選ぶ(優先順: O-Ren > 拡張版 > Kyoko)。
     ※Siriの声はSafariからは使えないので、Siri欄ではなく「声」欄から選ぶこと。URLに `&voice=名前` で直接指定も可
4. 機内モード(Wi-Fiオフ)にして同じURLを開き直し、**オフラインでも起動する**ことを確認。
   - セルフチェックに「△ サーバ: 接続なし → 内蔵の綾香(台本)で動きます」と出れば正常。
5. リハーサル: 「展示をはじめる」→ ことばのボタンで2〜3往復 → 放置してお別れ→待ち受けに戻るまでを一巡確認。

## 3. 当日の設営(会場)

1. iPadを**電源につなぐ**(必須。バッテリー運転は昼過ぎに死ぬ)。
2. Safariで展示URLを開く(ネットが無くても前日開いた殻で起動する)。
3. セルフチェック(✓/△)を確認 → **「展示をはじめる」を押す**。
4. **ホームボタン(またはサイドボタン)を3回押し → アクセスガイド開始**。
   - これでホームに戻れない・通知に触れない・他アプリに行けない「キオスク」になる。
5. 待ち受け表示になったら、ひとこと話しかけて(またはボタンを押して)応答を確認。
6. **綾香の置き手紙を設置**: 結末で綾香が「よかったら、あなたのために、お手紙を書きました。もらってください」と言う(風鈴の音つき)。**iPadの横に印刷した手紙を置いて、来場者が持ち帰れるように**しておく(封筒や便箋だと雰囲気が出る)。

## 4. 会期中の運用

- **朝**: 電源とアクセスガイドを確認 → 「展示をはじめる」を押すだけ。
- **無人中の自己回復(実装済み)**: マイクが落ちたら4秒ごとに立て直し/応答が90秒固まったら自動で初期化/ネットが切れたら内蔵の綾香に無音で交代/音声認識が死んだらタッチ運転に切り替え。
- **手動介入したいとき**: 左上のロゴを**5回タップ** → 操作パネル(文字入力・設定)が出る。
- **終了**: アクセスガイドを3回押し+パスコードで解除 → Safariを閉じる。

## 5. トラブルと対処

| 症状 | 対処 |
|---|---|
| 声が出ない | 「展示をはじめる」を押し直す(音声はこのボタンで解禁される)。本体のサイレントスイッチ/音量を確認 |
| マイクが反応しない | ネット接続を確認(iPadの音声認識はネット必須)。無ければ自動でタッチ運転になるので、そのままでOK |
| 会話が噛み合わない | ネット断で内蔵の綾香(台本)に切り替わった状態。仕様どおり。ネット復帰後は次の来場者からClaudeに戻る |
| 画面が暗くなる/ロック | 設定 > 自動ロック「なし」を再確認。電源接続を確認 |
| 完全に固まった | アクセスガイド解除 → Safariを引き上げて再起動 → URLを開き直し「展示をはじめる」 |
| 日次上限(Claude 50回/日)に達した | 自動で内蔵の綾香に切り替わり展示は続く。展示日は `web/wrangler.toml` の `DAILY_CALL_CAP` を600等に上げて `npx wrangler deploy`(終了後戻す) |

## 6. 展示日の前にやること(サーバ側・KASO) ※ネット運転する場合のみ

- [ ] `DAILY_CALL_CAP` 引き上げ(50 → 600目安)→ deploy(終了後戻す)
- [ ] Anthropic Consoleの月次spend上限を確認
- [ ] 会場のWi-Fi/テザリング事情を確認(無いと分かっているなら `&brain=offline` を付けて接続待ちを消す)
